# Example data

This folder contains some representative gait trials for demonstrating the pipeline.

Contents:
- sample_trial.c3d: Vicon acquisition of a mouse trotting over a force plate.

Purpose:
This dataset is provided solely to allow users to verify that the pipeline is installed correctly.

The data are not intended for scientific analysis.

Expected outputs:
- sample_trial.trc
- sample_trial_grf.mot
- sample_trial_grf.xml
